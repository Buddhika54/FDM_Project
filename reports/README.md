# Reports

Store evaluation artifacts and the written mini-project report here.

Suggested:

- `eda_summary.md` — from Phase 1
- `model_comparison.md` — copy from `templates/model_comparison.md`
- `best_params.md` — GridSearchCV results
- `figures/` — ROC curves, confusion matrices, EDA plots
- `final_report.pdf` or `.docx` — submission document

Templates live in `templates/`.
